# CVMaker

Construtor de currículos 100% frontend (React + TypeScript + Vite). Sem backend, sem cadastro: os dados ficam no LocalStorage do navegador.

- 3 modelos: Elegante (minimalista/ATS), Moderno (duas colunas) e Europeu (Europass)
- Preview A4 em tempo real, com paginação em várias páginas
- Exportação em PDF (com camada de texto), PNG e impressão
- Versão em inglês (rótulos + tradução dos textos via Translator API do Chrome 138+)
- Vários cargos na mesma empresa (promoções)
- Backup: baixar/carregar seus dados em JSON ("Meus dados")

## Rodando

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # build de produção (dist/)
```
